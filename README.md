# Mahaad Ar-Rayyan Girls Training Institute – Kibra (website)

Static site for GitHub Pages. Open index.html to preview locally.

- Gallery photos: put them in assets/gallery/ as photo1.jpg ... photo8.jpg (see the GALLERY comment in index.html)
- Hero banner photo (optional): assets/hero.jpg
- Payment number, WhatsApp number and photo count: edit the CONFIG block at the bottom of index.html
- Admission form: parents pay KES 500 by M-Pesa, send the confirmation on WhatsApp, and you reply with the PDF (kept in the PRIVATE folder, not on the website)
